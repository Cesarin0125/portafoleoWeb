# 💻 Portafolio Web Personal

Bienvenido a mi repositorio de portafolio web personal. Este proyecto está diseñado para presentar mis proyectos, habilidades técnicas y experiencia como desarrollador de software.

---

## 🚀 Características

* **Diseño Responsivo:** Adaptado para dispositivos móviles, tabletas y computadoras.
* **Interfaz Moderna:** Estructurada con secciones claras para experiencia, proyectos y contacto.
* **Muestrario de Proyectos:** Enlaces directos a mis aplicaciones desarrolladas (incluyendo aplicaciones web y backend en Flask).

---

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Estructura semántica del sitio.
* **CSS3:** Estilos, layout responsivo y efectos visuales (`style.css`).
* **JavaScript:** Interacción dinámica de la interfaz (`script.js`).

---

## 📂 Estructura del Proyecto

```text
portafoleoWeb/
